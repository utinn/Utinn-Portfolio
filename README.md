# UtinnPortfolio

Justin Christian Woeryadi's personal portfolio. React + Vite + Tailwind CSS, built against the approved Figma design (see `CLAUDE.md`, `docs/ANIMATION_SPEC.md`, `docs/INTERACTION_SPEC.md`).

## Scripts

```
npm run dev      # start the dev server
npm run build    # production build
npm run preview  # preview the production build
npm run lint     # oxlint
```
